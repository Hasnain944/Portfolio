# About this website

## Features

- Dark, responsive design with smooth scrolling and Framer Motion animations (respects the visitor's "reduce motion" setting)
- Sections: Home, About, Skills, Experience, Projects, Education and certifications, Contact
- Scroll-driven experience timeline and active-section highlighting in the navbar
- Mobile menu, keyboard-accessible navigation and a skip-to-content link
- Downloadable CV (`public/Hasnain-Ali-CV.pdf`)
- Contact form with validation. It opens Gmail with the message filled in, and has Copy-email fallbacks. It can send directly if a form endpoint is configured.
- SEO: page metadata, Open Graph and Twitter cards, generated social image, favicon, sitemap, robots.txt and structured data

## Tech stack

Next.js 15 (App Router), React 19, Tailwind CSS 3, Framer Motion, Lucide React.

## Run it on Windows 10 (PowerShell)

1. Install the **LTS** version of Node.js from https://nodejs.org, then reopen PowerShell and check:

```powershell
node -v
npm.cmd -v
```

> Use `npm.cmd` instead of `npm` so PowerShell's execution policy does not block it.

2. Open the project folder in VS Code and install dependencies:

```powershell
cd C:\Projects\hasnain-ali-portfolio
code .
npm.cmd install
```

3. Start the development server and open http://localhost:3000:

```powershell
npm.cmd run dev
```

4. Build and run the production version:

```powershell
npm.cmd run build
npm.cmd run start
```

## Customising

| What | Where |
| --- | --- |
| Name, email, phone, LinkedIn, GitHub, photo, site URL | `src/data/site.js` |
| Summary, skills, experience, projects, education, certifications | `src/data/profile.js` |
| Colours | `tailwind.config.js` |
| CV file | replace `public/Hasnain-Ali-CV.pdf` (same file name) |
| Profile photo | replace `public/profile.jpg` (about 800 x 1000 px works best) |

**Project images:** the pictures in `public/projects/` are generated illustrative previews, not real screenshots, and each card is labelled "Illustrative preview". To use a real screenshot, overwrite the image (16:10, about 1200 x 750 px) and delete the `illustrative: true` line for that project in `src/data/profile.js`. Add `live` and `github` links per project there too; empty values stay hidden.

**Contact form delivery:** by default the form opens Gmail. To receive messages directly, create a form endpoint (for example on https://formspree.io) and set it in `.env.local`:

```
NEXT_PUBLIC_FORM_ENDPOINT=https://formspree.io/f/your-id
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

## Deploy on Vercel

1. Push the project to a GitHub repository:

```powershell
git init
git add .
git commit -m "Initial portfolio"
git branch -M main
git remote add origin https://github.com/Hasnain944/YOUR-REPO.git
git push -u origin main
```

2. On https://vercel.com choose **Add New > Project**, import the repository and click **Deploy**.
3. In **Settings > Environment Variables** add `NEXT_PUBLIC_SITE_URL` (your live address), then redeploy.

**Custom domain:** in Vercel open **Settings > Domains**, add your domain, create the DNS records Vercel shows at your registrar (usually an A record `76.76.21.21` and a CNAME `cname.vercel-dns.com` for `www`), wait for the status to turn green, then update `NEXT_PUBLIC_SITE_URL` and redeploy.

## Troubleshooting

- **"running scripts is disabled" in PowerShell:** use `npm.cmd` instead of `npm`.
- **Port 3000 busy:** `npm.cmd run dev -- -p 3001`.
- **Strange errors after changing dependencies:** delete `node_modules` and `.next`, then run `npm.cmd install` again.
